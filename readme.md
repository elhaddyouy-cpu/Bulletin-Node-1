# Bulltin-Node-1

Projet de Gestion des Notes
Cette application console Node js gère et affiche les détails et les notes d'un étudiant à travers différentes phases.

# Étapes à complétées :

- Étape 1 Affichage de l'identité de l'étudiant.
- Étape 2 Affichage des notes en Histoire.
- Étape 3 Création d'une fonction paramétrable pour les notes.
- Étape 4 Affichage de la liste des notes de chaque matière.
- Étape 5 Boucle sur les clés d'un objet.
- Étape 6 Refacto : en faire un projet npm-compatible.
- Étape 7 Refacto : séparer les données (student json), les outils (tools js) et la logique (index js).
